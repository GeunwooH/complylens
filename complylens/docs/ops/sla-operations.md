# SLA Operations — 72-Hour Delivery

## SLA 정의
- 결제 완료 + 데이터 업로드 후 **72시간 내** 감사 보고서 + 공개 요약 + 고지 템플릿 납품
- 측정: 주문 상태 머신의 paid → delivered 타임스탬프 차이 (운영 로그)

## 72시간 보장 메커니즘 (C70 — DeepSeek SLA 없음 대응)
1. **멀티프로바이더 라우팅**: DeepInfra → DigitalOcean → OpenRouter 순 (비-PRC)
   - 프로바이더 장애 시 자동 페일오버 (LLMGateway.complete — 재시도 내장)
2. **재시도/백오프**: LLM 호출 3회 재시도 (2+1), 전부 실패 시 템플릿 내러티브 폴백
3. **비동기 배치**: 대량 파일은 피크 시간(베이징 9-12/14-18, C17) 회피 스케줄
4. **큐잉**: 동시 작업은 순차 처리 (동시성: Flash 2500 — C18, 병목 없음)
