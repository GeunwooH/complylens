# Pricing Strategy

## v1: $1,500 flat (2026-08-01 확정)
- 시장 실측: ll144audit.com $2,500, aedtaudits.com $1,500 (claim-graph C44 — 가격 하락 중)
- **시장 하단 진입** — 벤더 7개+ 경쟁에서 가격으로 차별화
- 감사당 LLM 원가: $0.02~0.07 (C45) — 마진 88.6%+ (C47)

## 티어 로드맵 (활성화 조건)
| 티어 | 가격 | 조건 |
|---|---|---|
| Standard (v1) | $1,500 | NYC LL144 단일 관할, 72시간 |
| Multi-state | $2,500 | IL/Colorado 현재 법령·시행일 재검증 및 evidence gate 통과 후 |
| Enterprise | $4,000+ | CA ADMT (2027-01-01) + 맞춤 ATS 통합 + 법무 검토 |

> IL·Colorado 법령 상태는 변경될 수 있다. 특정 법안 번호나 시행일만으로
> tier를 활성화하지 말고, 최신 공식 텍스트와 법무 검토를 먼저 확인한다.

## 원가 구조 (마진 유지 조건)
- API 비용: 수익의 <0.1% (C47) — 가격 결정 요인 아님
- 실제 원가: 독립 감사인 서명 시간 + 지원 (C50 — 자동화가 마진 결정)
- 피크 2배 정책 (C17): 비동기 배치로 비피크 시간 처리

## Wave 2: Kmong validation wedge

Stripe·감사 경로는 사용자 KYC와 독립성 게이트가 해소될 때까지 주력 채널로
사용하지 않는다. 크몽에서는 다음 단건 서비스만 검증한다.

- **범위:** 고객이 개인정보를 제거한 CSV 1개를 제출하면 데이터 프로파일과
  한국어 요약 리포트를 전달한다.
- **가격 가설:** KRW 300,000. 크몽 수수료·결제망·VAT 차감 후 금액은 카테고리
  확인 전 상한 가정으로만 계산한다.
- **제외:** 세무 신고·기장 대행, 지원금 신청서 작성·대리, 법률자문, 독립감사,
  개인정보가 든 원본 처리.
- **승격 게이트:** 승인 후 qualified 문의와 실제 처리 시간·수정 요청·환불을
  관측한 뒤에만 범위나 가격을 바꾼다.
