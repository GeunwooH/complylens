## EX-1 Kmong 범위 고정 서비스 (주력)

- **가설**: 비법률·비자문 범위 고정 서비스("1개 파일 정리 + 요약 리포트", KRW 300K)가
  심사 통과 후 14일 내 qualified 문의 5건을 만든다.
- **audience**: 데이터 정리·리서치·요약 리포트 외주가 필요한 한국 소상공인·1인 사업자·
  실무자. 법률·경영자문 카테고리는 피한다(자격 요구 리스크 — S087).
- **message (리스팅 문안 원칙)**: 결과물 단위로 명명("엑셀 1파일 정리 + 2페이지 요약 리포트"),
  특정 작업기간 명시, 가격에 포함 범위 내장. 금지: 외부 연락처 URL, "최고/유일" 절대 표현,
  범위와 분리된 가격, 모호한 납기 (S085). "법률 준수 보장" 문구 금지.
- **CTA**: 크몽 플랫폼 내 "문의하기/견적 요청". 모든 소통은 플랫폼 메시지 안에서만 —
  거래 전 외부 연락처 공유·유도는 금지 행위(크몽 모니터링 규정)다.
- **측정**: 크몽 판매자 대시보드의 노출/조회/문의를 일별 기록. 퍼널 = 노출 → 조회 →
  문의 → 견적 → 계약 → 납품. 수령액 = 가격 × (1 − 유효수수료); 최저구간 유효부담 약
  21.67%(누적 구간 16.4%/9.4%/4.4% + 결제망 3.3% + 수수료 VAT — S081).
- **성공 조건**: 승인 후 14일 내 qualified 문의(문제·예산·납기 확인) ≥ 5건 또는 유료 계약 ≥ 1건.
- **중단 조건 (반증)**: 승인 후 7영업일 내 문의 < 5건이면 문구·카테고리 1회만 수정;
  재등록 후에도 14일간 문의 0건이면 채널 중단. 심사 거절 시 같은 문구 반복 금지 —
  비법률 데이터 서비스로 범위를 좁혀 재등록, 2회 거절 시 중단. 심사가 10영업일을 넘기면
  1:1 문의로 원인을 기록하고 "플랫폼 차단" 상태로 분류한다.
- **사용자 게이트**: 미저장 draft의 폼 오류 확인·저장·제출(계정 실소유자만 가능).

## EX-2 직접 아웃리치 — 사용자 승인 건별 발송

- **가설**: 선별된 실구매 후보 20명에게 건별 맞춤 제안을 보내 응답률 ≥ 10%,
  qualified 리드 ≥ 2명, 계약 1건을 만든다.
- **audience lane A (미국, CAN-SPAM)**: `soc2-growth-sprint.md`의 founder 20명 선정 기준 —
  SOC2가 계약 조건으로 걸린 프리시드~시리즈A SaaS의 founder/security 리드.
  근거 있는 공개 연락 경로만 사용, 개인 이메일 추측 금지.
- **audience lane B (국내, 정보통신망법 §50)**: **사전 수신동의 없는 영리목적 광고성
  메시지 전송은 금지(과태료)**. 따라서 국내 lane은 (a) 사용자가 이미 관계·동의를 가진
  연락처, (b) 거래 문의를 먼저 보낸 상대로만 제한한다. 크몽 과거 대화 상대를 플랫폼
  밖으로 유도하는 것도 EX-1 규칙상 금지. 국내 콜드 이메일은 이 실험 범위에서 제외한다.
- **message (미국 lane 초안 뼈대)**: 1) 상대 회사 특정 사실 1문장, 2) SOC2 evidence
  coordination / LL144 연례 감사 중 상대에게 해당하는 문제 1문장, 3) 우리가 실제로
  한 일(통계 엔진, 72시간 납품) 1문장, 4) 회신 또는 거절 의사 존중 1문장. 발신자 실정보·
  주소·수신거부 경로 포함(CAN-SPAM — S090). 허위·과장, "compliance guaranteed" 금지.
- **CTA**: 회신(대화 시작) 또는 UTM 링크
  `?utm_source=founder&utm_medium=direct&utm_campaign=soc2-v1` (랜딩 → 리드 폼).
- **측정**: 발송/수신/회신/qualified/계약 일별 로그 + 리드 JSON attribution.
- **성공 조건**: 20건 발송 기준 회신 ≥ 2건(10%)이고 그 중 qualified ≥ 1건.
- **중단 조건 (반증)**: 승인 후 14일 내 20건 발송 자체가 불가능하면(사용자 시간 부재 등)
  채널을 "게이트 차단"으로 기록하고 예측에서 제외. 20건 발송 후 회신 < 2건이면 메시지
  1회 수정 후 10건 재발송; 그래도 회신률 < 10%면 중단. 수신거부 요청은 즉시 반영하고
  로그에 남긴다.
- **사용자 게이트**: 발송 건별 승인 + 실제 발송(에이전트는 SMTP·계정 없음).

- **가설**: 규제 의무 키워드("LL144 bias audit requirements" 등) 콘텐츠가 색인되면
  비 UTM 방문을 만든다. 단, 30일 주력 채널이 아니다(C12 — 방향성 결론).
- **현재 실측 (2026-08-02)**:
  1. `site:html.npopo.com` 검색 색인 결과 0건(DDG, directional).
  2. **robots.txt 버그**: `Sitemap:` 지시자가 플레이스홀더 `https://complylens.example/sitemap.xml`
     을 가리킴 — 실제 사이트맵(28 URLs)이 크롤러에 연결되지 않은 상태. 수정 전까지
     SEO 실험은 무효. 워킹트리에서 production URL로 수정했지만, 커밋·배포·
     배포본 재실측 전까지 해결된 것으로 세지 않는다.
  3. `/api/pv`는 경로만 기록하고 referrer를 기록하지 않음 — organic 세션을 직접 트래픽과
     구분 불가. 최소 계측 보완(referrer 필드 추가) 전에는 판정 신뢰도가 낮다.
- **audience**: 자기 의무를 검색하는 미국 고용주/HR(유통 결론: 구매자는 제품 카테고리가
  아니라 자기 의무를 검색).
- **message/CTA**: 기존 블로그 18편 → 체크리스트 CTA → pricing. UTM 보존 파이프라인은
  C001에서 검증 완료. 신규 콘텐츠는 월 2편 상한(확장은 방문 측정 후).
- **측정**: Day 0 베이스라인 = 색인 확인(site: 쿼리 + 가능 시 Search Console, 사용자 계정),
  robots/sitemap 수정. 30일 = 비 UTM 블로그 PV, source=organic 수동 태그 리드.
  ab-test-plan.md의 전환 실험은 주간 방문 100+ 또는 첫 리드 시에만 트리거.
- **성공 조건**: 30일 내 색인 페이지 ≥ 1 확인되고 비 UTM 블로그 방문이 일평균 ≥ 1.
- **중단 조건 (반증)**: robots 수정 후 30일간 색인 확인 0건 또는 방문 ≈ 0이면 콘텐츠
  추가 없이 배경 유지. 방문이 생기면 EX-1~4의 보조 유입으로만 사용하고 SEO 독립 투자는
  30일 후 재평가.
- **사용자 게이트**: Search Console 등록 시 계정 필요(선택).

## 전역 중단 규칙

1. 도달 자체가 0인 채널에는 콘텐츠·광고를 추가하지 않는다(SYNTHESIS: traffic 0 → 매출 0).
2. 누적 qualified 대화·주문·구매확정·처리시간·환불을 함께 기록한다. 작은 표본의
   고정 “5명·20%” pass/fail 판정은 사용하지 않고 buyer/channel fit을 먼저 수정한다.
3. "pass/certified/compliance guaranteed" 표현, 독립감사 사칭, 플랫폼 외부 연락처 유도,
   사전동의 없는 국내 광고성 메시지 전송은 어떤 실험에서도 금지.
