# 수동 데이터 정리·요약 리포트 운영 런북

이 런북은 크몽의 범위 고정 문서·데이터 서비스에만 적용한다. 산출물은
데이터 정리·요약 리포트이며 세무 신고, 세무대리, 법률자문, 감사 의견이 아니다.

## 입력 게이트

1. 고객에게 구매자 이름·전화번호·주소·주민번호·계좌번호가 포함되지 않은
   집계형 CSV를 요청한다.
2. 원본에 개인정보가 있으면 고객이 자체 마스킹한 파일을 다시 제출할 때까지
   작업을 시작하지 않는다.
3. 현재 도구는 UTF-8 CSV만 지원한다. XLSX는 변환 후 다시 확인한다.
4. 파일을 외부 LLM이나 제3자 API로 보내지 않는다. 프로파일링은 로컬 CLI에서
   수행한다.

## 실행

```bash
uv run python -m complylens.fulfill input.csv output/
```

생성물:

- `profile.json`: 행 수, 결측, 고유값, 숫자 범위, 중복 행
- `summary.html`: 고객에게 전달할 한국어 요약 리포트

## 납품·삭제

- 결과물은 숫자·구조 중심으로 검토하고 원본 파일과 대조한다.
- 리포트에 법률·세무·감사 보장 표현을 추가하지 않는다.
- 크몽 메시지로 결과물을 전달하고, 원본·중간 파일은 계약상 보관 필요가
  사라지는 즉시 삭제한다.
- 주문별 실제 처리 시간과 수정 요청을 기록해 다음 가격·범위를 조정한다.

## 중단 조건

- 개인정보가 마스킹되지 않은 파일
- 열 의미가 불명확하거나 행 구조가 깨진 파일
- 신고서 작성, 세무 판단, 법률 결론, 감사 서명을 요구하는 요청
