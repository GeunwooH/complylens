# Case Study Template (합성 데이터 전용)

> 규칙: 실고객 데이터 사용 금지 — 모든 사례 연구는 합성 데이터로 생성 (C46, 개인정보)

## 구조
1. **고객 상황**: "AI 기반 채용 스크리너를 사용하는 미드사이즈 B2B 기업 (가상)"
2. **과제**: NYC 채용 포지션 대상 AEDT 사용 — LL144 연례 감사 의무 (C1)
3. **접근**: CSV 내보내기 → 통계 엔진 (selection rate / impact ratio / four-fifths) → 독립 감사인 검토 → 납품
4. **결과**: 72시간 내 납품, 위반 지표 식별 + 시정 권고, 공개 요약 게시
5. **수치 예시 (합성)**: "12,400건 지원서 분석, 교차범주 6개 평가, 3개 범주에서 four-fifths 미달 식별"

## 검증 가능한 수치만 사용
- 모든 통계는 합성 데이터에서 실제 계산 (예: tests/ 샘플 CSV 기반)
- LLM 생성 수치 금지 — 환각 게이트 (C35)
