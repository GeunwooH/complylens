Is Your LL144 Bias Audit Expired?

NYC Local Law 144 requires a bias audit completed within the last 12 months. If yours was done before August 2025, it is expired today — and with enforcement now proactive, expiry is no longer a paperwork detail.

Expired audit = non-compliant use. Penalties run per day: $500 first violation, $500–$1,500 per day after, per tool. Each day the expired tool keeps screening NYC candidates accrues exposure. 30 days ≈ $15,000–$45,000 per tool.

Renewal checklist

  1. Check the date: find your last audit's completion date (not the report date — the audit completion).
  2. Confirm the public summary is current: the posted summary must reflect the most recent audit.
  3. Export fresh data: the renewal needs data covering the period since the last audit — see our data export guide.
  4. Run the new analysis: selection rates, impact ratios, four-fifths per DCWP Final Rules.
  5. Update the public summary and candidate notice with the new audit date.
  6. Set the next renewal: 12 months from the new audit date.

How long does renewal take?

If your data export is ready, automated statistical analysis takes 72 hours. Independent auditor sign-off (required for legal effectiveness) can be coordinated separately.

Common mistakes

  • Reusing last year's report without re-running the analysis — the audit must reflect the current tool and data.
  • Only auditing the tool, not the selection process the tool feeds.
  • Forgetting score-based tools need median-threshold scoring analysis, not just binary selection rates.
