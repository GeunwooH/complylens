The common core

Every regime ultimately asks the same question: does your AI tool treat protected groups differently, and can you prove you checked? The statistical analysis — selection rates, impact ratios, four-fifths assessment — is the shared foundation. Once you compute it for NYC, the same numbers feed Illinois disclosure, Colorado's impact assessment, California's future risk assessments, and the EU's documentation requirements.

Practical strategy

  1. Inventory every AI-assisted hiring tool and the states/regions where you hire.
  2. Run the statistical analysis once — it's the common core.
  3. Generate per-jurisdiction documents from the same numbers.
  4. Set the annual re-audit calendar — every regime requires freshness.
