Why this matters

LL144's audit requirement is unique — no other state yet mandates the specific statistical audit NYC does. But Illinois adds disclosure duties for the same tool, and California's ADMT rules will add risk assessments on top. An employer using one ATS across all three states faces three different paper trails.

The pragmatic path

The statistical analysis is the common denominator: if you already compute selection rates and impact ratios for NYC, the same data supports Illinois disclosure and California's future assessments. ComplyLens reports include an Illinois notice section in multi-state packages, so one data upload covers more than one obligation.
