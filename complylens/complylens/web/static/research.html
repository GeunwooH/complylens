10. 결론 및 추천 (확정)

핵심 판정 5개

  1. “싼 토큰 = 기회”는 기각 — 모든 후보에서 LLM 원가 < 납품가의 1% (C45, C47). 가격은 필요조건일 뿐, 사업 선택 기준은 지불의사/유통/신뢰/규제 자격.
  2. DeepSeek V4의 진짜 이점: 추론 출력 멀티플라이어 없음 (경쟁사 대비 7~50배, C63) + 캐시 히트 2% + 1M 컨텍스트 + MIT 오픈웨이트 코모디티화 (C72).
  3. 한국어 사용자 대상 서비스는 구조적 NO-GO (C65~C69): PIPA 중국 이전 + 한국어 미검증 + K-ExaOne/HyperCLOVA + 무료 온보딩. → 타깃은 글로벌/영어권.
  4. DeepSeek 직접 API는 단독 의존 불가 — “모델에 구축하되 벤더에 구축하지 마라” (C75): 멀티프로바이더 라우팅 + 규제 데이터 비-PRC + 자체호스팅 폴백.
  5. 규제 컴플라이언스가 유일한 “DeepSeek이 게임을 바꾸는” 영역 (C46): 1M 컨텍스트로 규제 전문 원문 통째 입력 + 다중관할 산출물 (LL144 감사, IL HB 3773, CA ADMT, EU) — 단 도메인 전문성 필수.
