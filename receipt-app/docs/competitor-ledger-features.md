## 미검증 후보 (경쟁사 소스에서 직접 확인 못함 — 업계 표준 패턴)

스토어 설명·공식 사이트에 명시가 없어 출처 없는 후보로 분리. 우리 앱 스코프(장부 탭) 기준 평가.

| # | 기능 | 무료 티어 가치 평가 | 구현 난이도 |
|---|---|---|---|
| 15 | 거래 검색 (거래처/메모/금액) + 카테고리·기간 필터 | **즉시 가치 / 높음** — 거래 수가 늘수록 목록만으로는 한계; 구현 비용 대비 체감 최고 | 하 |
| 16 | 정렬 (날짜/금액 오름·내림) | **즉시 가치 / 높음** — 필터와 세트, 사실상 테이블 기본기 | 하 |
| 17 | 거래 태그 (자유 라벨, #공제대상 등) | **즉시 가치 / 중간** — 카테고리 보완재지만 입력 부담 증가; 파워 유저용 | 중 |
| 18 | 거래 일괄 수정/삭제 (다중 선택) | **즉시 가치 / 중간** — OCR 오류 정리·월 마감 시 유용하지만 사용 빈도 낮음 | 중 |
| 19 | 카테고리별 월 예산 설정 + 초과 알림 | **즉시 가치 / 중간** — 개인 가계부적 기능; 사업자에겐 "예상 세액"(#8)이 더 절실 | 중 |
| 20 | 재고 관리 | **복잡성만 증가 / 낮음** — 어느 경쟁사 장부에도 없음(얼마365 발주서는 문서 발행); 별도 앱 영역 | 상 |
